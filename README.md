## 📘 Descripción general del sistema

Este proyecto es mi Evaluación Final Transversal de Fundamentos de Programación. Es un programa en Java para llevar el control de la bencina que gastan los vehículos de una empresa.

Se ingresa la patente, los kilómetros recorridos y los litros cargados, y el programa calcula cuántos kilómetros rinde el vehículo por litro. Los registros se guardan en un archivo de texto, así que no se pierden al cerrar el programa.

Con los datos guardados se pueden ver todos los registros, calcular el promedio, el mejor y el peor rendimiento, y filtrar los vehículos que rinden menos de 10 km/L.
